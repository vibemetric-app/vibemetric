# Security policy

## Report a vulnerability

Do not open a public issue for a security problem. Report it privately through GitHub:
go to the **Security** tab of this repository and click **Report a vulnerability**.

Include the steps to reproduce the problem, the affected version, and the effect. We reply within 7 days.

## Scope

- This repository: the free Mac app, the evidence pack, the redaction of transcripts, and the calls to the Claude Code and Codex CLIs.
- The official app's update check (Sparkle) and Pro features: report them the same way.

## Supported versions

We fix security problems in the latest release only. Update through **Vibemetric → Check for Updates…**, or build again from `main`.
